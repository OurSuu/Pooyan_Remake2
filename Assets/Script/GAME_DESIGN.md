# 🎮 Pooyan Remake — Game Design Document
# Faithful Recreation of Konami's Pooyan (1982 Arcade)

> **วัตถุประสงค์:** สร้างเกม Pooyan ใน Unity 2D ให้ตรงกับต้นฉบับ Konami 1982 Arcade 100%
> **Engine:** Unity 2D
> **Language:** C#
> **แหล่งอ้างอิง:** StrategyWiki, Wikipedia, Namu Wiki, GameSpot, ClassicReload, Japanese arcade sources

---

## 1. ภาพรวมเกม (Game Overview)

- **ชื่อเกม:** Pooyan
- **ผู้เล่น:** 1 คน
- **ประเภท:** Fixed-Screen Shooter
- **ตัวละครหลัก:** Mama Pig (แม่หมู) — ขี่กระเช้า (Gondola/Elevator) เคลื่อนที่ขึ้น-ลง
- **ศัตรู:** หมาป่า (Wolves) — ใช้ลูกโป่งลอยขึ้น/ลง
- **เป้าหมาย:** ยิงลูกโป่งหมาป่าให้ร่วงก่อนถึงจุดหมาย, ป้องกันลูกหมู

---

## 2. ระบบควบคุม (Controls)

| Input | Action |
|---|---|
| ↑ / ↓ (Joystick/Keyboard) | เลื่อนกระเช้าขึ้น/ลง บนราง |
| Fire Button (Space/Z) | ยิงลูกธนู / โยนเนื้อ (ถ้าถือเนื้ออยู่) |

- กระเช้าเคลื่อนที่ได้เฉพาะแนวตั้ง (Vertical Only)
- มีขอบเขตบน/ล่างของราง

---

## 3. ระบบด่าน (Stage System)

### 3.1 โครงสร้างด่าน

```
Level 1 = Stage 1 (Descending) → Stage 2 (Ascending) → Bonus Stage
Level 2 = Stage 3 (Descending) → Stage 4 (Ascending) → Bonus Stage
Level 3 = Stage 5 (Descending) → Stage 6 (Ascending) → Bonus Stage
... วนซ้ำ ยากขึ้นเรื่อยๆ ...
```

### 3.2 ด่านคี่ — Descending Stage (1, 3, 5, ...)

- หมาป่าลอยลงจากยอดไม้/หน้าผาด้านบน ใช้ลูกโป่ง
- ผู้เล่นอยู่ฝั่งขวา ยิงไปทางซ้าย
- **ถ้าหมาป่าลงถึงพื้น:**
  - หมาป่าเดินไปปีนบันไดด้านหลังกระเช้า
  - รอคอยอยู่บนบันได
  - **กัด** ทันทีที่กระเช้าเลื่อนลงมาถึงตำแหน่งที่มันอยู่ = **ตาย**
- **จบด่าน:** หมาป่าทั้งหมดถูกกำจัด หรือลงพื้นหมด (ถ้ายังไม่ตาย)

### 3.3 ด่านคู่ — Ascending Stage (2, 4, 6, ...)

- หมาป่าอยู่ด้านล่าง พองลูกโป่งแล้วลอยขึ้น
- ผู้เล่นอยู่ฝั่งขวา ยิงไปทางซ้าย
- **ถ้าหมาป่าขึ้นถึงหน้าผาด้านบน:**
  - จะไปรวมกลุ่มบนหน้าผา
  - **ครบ 7 ตัว = ผลักก้อนหินใหญ่ (Boulder) ลงมาทับกระเช้า = ตาย**
- **Boss Wolf (Flashing Balloon):**
  - ปรากฏในด่านคู่ เป็นตัวสุดท้ายหรือใกล้สุดท้าย
  - ใช้ **ลูกโป่งกระพริบสีแดง (Flashing Red Balloon)**
  - ถือโล่ที่ทนลูกธนูได้ **5 นัด** (นัดที่ 6 ทะลุถึงลูกโป่ง)
  - **ยิง Boss Wolf สำเร็จ = จบด่านทันที** (ไม่ว่าจะเหลือหมาป่าอื่นกี่ตัว)
  - โดนเนื้อ = ตายทันที (เนื้อทะลุโล่)
  - **เนื้อจะหยุด spawn ก่อน Boss Wolf ปรากฏ** (ต้อง save เนื้อไว้ล่วงหน้า)
- **จบด่าน:** หมาป่าทั้งหมดถูกกำจัด หรือ ยิง Boss Wolf สำเร็จ

### 3.4 Bonus Stage

เกิดขึ้นหลังด่านคู่ทุกครั้ง มี **2 แบบสลับกัน:**

#### Bonus Type A — Fruit Bonus
- ผลไม้ตกลงมาจากด้านบน
- ยิงผลไม้เก็บคะแนน:
  - Strawberry = **100 แต้ม**
  - Cherry = **200 แต้ม**
  - Peach = **400 แต้ม**
- ไม่มี Game Over / ไม่เสีย Life

#### Bonus Type B — Meat Bonus
- หมาป่าลอยออกมาเป็นแพทเทิร์น
- ใช้เนื้อกวาดให้ได้มากที่สุด
- คำนวณคะแนนตามระบบคอมโบ
- ไม่มี Game Over / ไม่เสีย Life

## 4. ระบบอาวุธ (Weapons)

### 4.1 ลูกธนู (Arrow)

| คุณสมบัติ | ค่า |
|---|---|
| **วิถี** | **เส้นตรงแนวนอน (Straight Line)** — ไม่มี gravity/parabolic |
| **จำนวนบนจอ** | สูงสุด **2 ลูก** พร้อมกัน |
| **ความเร็ว** | คงที่ |
| **ใช้งานได้** | เฉพาะเมื่อไม่ได้ถือเนื้อ |

#### Collision Rules ของลูกธนู:

| โดนอะไร | ผลลัพธ์ |
|---|---|
| ลูกโป่ง (Normal, HP=1) | ลูกโป่งแตก → หมาป่าร่วง |
| ลูกโป่ง (Multi-Hit, HP>1) | ลูกโป่งเสีย 1 HP, แสดง visual feedback (หดลง) |
| ลูกโป่งกระพริบ Boss | ต้องทะลุโล่ก่อน (5 นัด) → นัดที่ 6 ถึงโดนลูกโป่ง |
| ตัวหมาป่า (ลำตัว) | **ไม่มีผล** — ลูกธนูหายไป หมาป่าไม่เสียหาย |
| โล่หมาป่า | **ลูกธนูถูกบล็อก/สะท้อน** — หมาป่าไม่เสียหาย |
| หิน (ที่หมาป่าปามา) | หินถูกทำลาย → **200 แต้ม** |
| ผลไม้ (Boss Wolf ยอดไม้ปามา) | ผลไม้ถูกทำลาย → **200 แต้ม** |
| ขอบจอ | ลูกธนูหายไป |

### 4.2 เนื้อ (Meat Weapon)

| คุณสมบัติ | ค่า |
|---|---|
| **วิถี** | **Parabolic (โค้งพาราโบลา)** — มี gravity |
| **Piercing** | ✅ ทะลุทะลวง — ไม่หายเมื่อโดนศัตรู กวาดทุกตัวในแนวตก |
| **จำนวน** | 1 ก้อนต่อครั้ง |
| **เงื่อนไขหยิบ** | กระเช้าต้องเลื่อนไปจุด **สูงสุดของราง** ถึงจะหยิบเนื้อได้ |
| **ข้อจำกัด** | ไม่สามารถยิงลูกธนูขณะถือ/โยนเนื้อ |
| **ทะลุโล่** | ✅ เนื้อไม่ถูกโล่บล็อก — โดน Boss Wolf ตายทันที |
| **การปรากฏ** | ปรากฏเป็นระยะที่จุดสูงสุดของเชือกกระเช้า |
| **หยุด spawn** | เนื้อหยุดปรากฏเมื่อ Boss Wolf กำลังจะเข้าฉาก |

### 4.3 ระบบคอมโบเนื้อ (Meat Combo Scoring)

เมื่อโยนเนื้อ 1 ก้อนแล้วกวาดหมาป่าหลายตัว:

| ลำดับหมาป่าที่ร่วง | คะแนน |
|---|---|
| ตัวที่ 1 | **400** |
| ตัวที่ 2 | **800** |
| ตัวที่ 3 เป็นต้นไป | **1,600** (cap คงที่ ไม่เพิ่มอีก) |

**ตัวอย่าง:** เนื้อ 1 ก้อนกวาดได้ 5 ตัว = 400 + 800 + 1600 + 1600 + 1600 = **6,000 แต้ม**

## 5. ระบบลูกโป่ง (Balloon System)

### 5.1 ประเภทลูกโป่ง

| ประเภท | HP | Visual | หมายเหตุ |
|---|---|---|---|
| Normal (สีเหลือง/แดง) | 1 | ปกติ | โดน 1 นัดแตก |
| Multi-Hit (ด่านหลังๆ) | 2-5 | หดลงทีละนิดเมื่อโดนยิง, เปลี่ยน Sprite ตามดาเมจ | HP เพิ่มตามระดับด่าน |
| Boss Flashing (กระพริบแดง) | 1 (แต่มีโล่ 5 นัดก่อน) | **กระพริบสีแดง** สลับสว่าง/มืด | เฉพาะ Boss Wolf ด่านคู่ |

### 5.2 Visual Feedback เมื่อโดนยิง (Multi-Hit)

1. ลูกโป่งหดเล็กลงทีละขั้น
2. เปลี่ยน Sprite Stage (เช่น ปกติ → บวม → แตกร้าว)
3. อาจกระพริบสั้นๆ เมื่อโดนยิง

## 6. ระบบศัตรู (Enemy System)

### 6.1 หมาป่าธรรมดา (Normal Wolf)

**State Machine:**

```
[Spawn] → [Floating] → [Reached Destination?]
                              ├── Yes (ด่านคี่) → [Walk to Ladder] → [Climb Ladder] → [Wait & Bite]
                              ├── Yes (ด่านคู่) → [Join Cliff Group] → [Count towards Boulder]
                              └── No (ลูกโป่งแตก) → [Falling] → [Dead/Removed]
```

#### พฤติกรรมขณะลอย (Floating Behaviors):

| พฤติกรรม | รายละเอียด |
|---|---|
| **ความเร็ว** | แต่ละตัวมีความเร็วสุ่มต่างกัน (บางตัวเร็ว/ช้า) |
| **โล่ (Shield)** | บางตัวถือโล่ ยกขึ้นบังเป็นจังหวะ → ต้องกะจังหวะยิงตอนลดโล่ |
| **ปาหิน (Rock Throwing)** | บางตัวปาหินสวนกลับมาที่กระเช้า → ผู้เล่นต้องหลบ หรือ ยิงหินทำลาย (200 แต้ม) |
| **Passive Deflection** | ยิงโดนลำตัวหมาป่า = ไม่มีผล ลูกธนูหายไป (ต้องยิงลูกโป่งเท่านั้น) |

### 6.2 Boss Wolf — ด่านคู่ (Ascending Boss)

| คุณสมบัติ | ค่า |
|---|---|
| ลูกโป่ง | **กระพริบสีแดง (Flashing Red)** |
| โล่ | ทนลูกธนู **5 นัด** → นัดที่ 6 ทะลุถึงลูกโป่ง |
| โดนเนื้อ | **ตายทันที** (เนื้อทะลุโล่) |
| ยิงสำเร็จ | **จบด่านทันที** ไม่ว่าเหลือหมาป่าอื่นกี่ตัว |
| ปรากฏเมื่อ | เป็นตัวสุดท้ายหรือใกล้สุดท้ายของ wave |
| เนื้อ spawn | **หยุดปรากฏ** ก่อน Boss มา → ต้อง save เนื้อล่วงหน้า |

### 6.3 Boss Wolf — ยอดไม้ (TreeTop Boss) — Stage 3+

| คุณสมบัติ | ค่า |
|---|---|
| ตำแหน่ง | เดินไปมาบนยอดไม้ (ด้านบนจอ) |
| พฤติกรรม | ปาผลไม้ลงมาในแนวจอ |
| ผลไม้ที่ปา | ยิงทำลายได้ → **200 แต้ม** |
| อันตราย | ผลไม้อาจบดบังลูกธนูหรือรบกวนการยิง |

### 6.4 ระบบบันได (Ladder System) — ด่านคี่เท่านั้น

1. หมาป่าที่ลงถึงพื้น → เดินไปที่บันไดด้านหลังกระเช้า
2. ปีนบันไดขึ้นไป → หยุดรออยู่บนบันได
3. **กัดทันที** เมื่อกระเช้าเลื่อนลงมาถึงตำแหน่งที่มันอยู่ = **ตาย**
4. หมาป่าหลายตัวสามารถปีนบันไดพร้อมกัน คนละขั้น

### 6.5 ระบบก้อนหิน (Boulder System) — ด่านคู่เท่านั้น

1. หมาป่าที่ลอยขึ้นถึงหน้าผาด้านบน → ไปรวมกลุ่มบนหน้าผา
2. UI แสดงจำนวนหมาป่าบนหน้าผา (เช่น counter หรือ icon)
3. **ครบ 7 ตัว** → Animation ผลักก้อนหิน → หินตกลงมาทับกระเช้า = **ตาย**

## 7. ระบบคะแนน (Scoring System)

### 7.1 ตารางคะแนนพื้นฐาน

| Action | คะแนน |
|---|---|
| ยิงลูกโป่งแตก (ลูกธนู) | **100** |
| หมาป่าร่วง (จากลูกโป่งแตก) | คะแนนเพิ่มตาม stage |
| ยิงหินทำลาย | **200** |
| ยิงผลไม้ (Boss ยอดไม้) ทำลาย | **200** |
| เนื้อคอมโบ ตัวที่ 1 | **400** |
| เนื้อคอมโบ ตัวที่ 2 | **800** |
| เนื้อคอมโบ ตัวที่ 3+ | **1,600** (cap) |
| Bonus Stage — Strawberry | **100** |
| Bonus Stage — Cherry | **200** |
| Bonus Stage — Peach | **400** |

### 7.2 ระบบ Lives

- เริ่มต้น **3 Lives**
- **เงื่อนไขเสีย Life:**
  - ด่านคี่: หมาป่าบนบันไดกัดกระเช้า
  - ด่านคู่: หมาป่า 7 ตัวผลักก้อนหินลงมา
  - ทุกด่าน: โดนหินที่หมาป่าปามา (ถ้าไม่หลบ/ไม่ยิงทำลาย)
- **Game Over:** Lives = 0

## 8. ระบบความยาก (Difficulty Progression)

เมื่อด่านสูงขึ้น:

| พารามิเตอร์ | การเปลี่ยนแปลง |
|---|---|
| จำนวนหมาป่าต่อ wave | เพิ่มขึ้น |
| ความเร็วหมาป่า | เร็วขึ้น |
| สัดส่วนหมาป่ามีโล่ | เพิ่มขึ้น |
| สัดส่วนหมาป่าปาหิน | เพิ่มขึ้น |
| HP ลูกโป่ง (Multi-Hit) | เพิ่มจาก 1 → 2 → 3 → 4 → 5 |
| ความถี่ในการยกโล่ | บ่อยขึ้น |
| Boss Wolf โล่ทน | อาจเพิ่มขึ้นในด่านลึกๆ |
| Boss Wolf ยอดไม้ | ปรากฏตั้งแต่ Stage 3 |
